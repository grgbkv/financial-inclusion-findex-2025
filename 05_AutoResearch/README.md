# 05_AutoResearch — the pre-registered research loop (paper two of two)

An autonomous empirical-research loop over the same Findex data. It runs pre-registered
experiments and logs **every one of them — kept and discarded** — to an append-only ledger.

**98 experiments · 41 keeps · 48 discards.** Roughly half of everything tried failed its own
threshold, which is the number that makes the other half worth reading.

## What's where

| looking for | file |
|---|---|
| the current write-up | **[`PAPER_DRAFT_v5.md`](PAPER_DRAFT_v5.md)** — *A balance-sheet window* |
| one line per experiment | **[`LEDGER_INDEX.md`](LEDGER_INDEX.md)** — generated, never hand-edited |
| the rules and why each exists | **[`program_findex.md`](program_findex.md)** |
| what runs next | [`RESEARCH_AGENDA.md`](RESEARCH_AGENDA.md) |
| the machine-readable ledger | [`findings.tsv`](findings.tsv) |

`RESEARCH_LOG.md` is the unabridged record: every pre-registration and every verdict, in full,
appended and never rewritten. At 550 KB it is built to be searched one experiment at a time rather
than read straight through — which is exactly why `LEDGER_INDEX.md` exists alongside it, and why
that index is what each cycle opens with.

## How the discipline works

1. **Pre-register before looking.** Hypothesis, exact test and keep threshold go into
   `RESEARCH_LOG.md` *before* the answer is computed, and the experiment is committed before it is
   run. An answer peeked at first can never be logged as a keep.
2. **The harness is fixed.** All data access goes through `harness.py` (country level) and
   `micro.py` (individual level). Neither may be edited during a run, so the rigor gates — coverage,
   official-aggregate cross-check, jackknife sign-stability — cannot be skipped by construction.
3. **Keep only if the pre-registered bar and every gate pass.** Otherwise it is a discard, and the
   discard is logged with the same care as a keep.
4. **Nothing is causal.** Every claim is worded as a descriptive association.

Rules accumulate as amendments in `program_findex.md`, each recording the experiment that forced
it — because a rule whose reason is not written down gets dropped by the next cycle that finds it
inconvenient.

## Three things it found that the notebook could not

**Replication is where claims go to die.** Every *level-to-change* design has failed: **0 keeps
in 7 attempts**. The *partial* designs kept three, and every one of those later put to a
replication or promotion test failed — so all three remain **window** claims. Since the promotion
rule was tightened, three promotions have been attempted and three have failed. The six
associations that were promoted to general claims got there by being tested across wave
transitions rather than inside one.

**Population weighting is doing more work than it looks.** A population-weighted correlation over
~77 economies has a Kish effective sample size near **7**. The ledger now reports the unweighted
twin beside every weighted statistic and names the single economy whose removal moves the result
most — on one cell, dropping China alone moves *r* from +0.198 to +0.726.

**Denominators drift.** A ledger-wide audit found six economies that stop reporting individual
survey items between 2021 and 2024 while remaining in the wave. On the affected items this
manufactures apparent co-movement: three of four margins in one module stop moving at all once the
economy set is held fixed.

## Layout

```
PAPER_DRAFT_v5.md     the current draft — the highest-numbered draft at this level is the live one
archive/              superseded drafts (v2, v3, v4), each marked SUPERSEDED in its own header
program_findex.md     protocol + every amendment
RESEARCH_AGENDA.md    the seven programs and the running addenda
RESEARCH_LOG.md       the unabridged append-only record; searched, not read straight through
LEDGER_INDEX.md       generated by make_index.py from findings.tsv
findings.tsv          the ledger; results_prediction.tsv is the prediction stream's
harness.py micro.py coverage.py    frozen by the protocol; untouched while experiments run
experiment.py micro_experiment.py predictor.py    the current cycle's code
make_index.py         loop-owned tooling; `--check` validates the ledger's structural rules
runs/                 raw stdout of past experiment runs, kept as evidence
```

`archive/` and `runs/` were introduced when the repository was reorganised. Nothing reads either
one programmatically, and the live draft stays at this level so the distillation trigger — which
reads *the highest-numbered `PAPER_DRAFT_v*.md` in this folder* — resolves exactly as before.

Two conventions keep it that way. A cycle's captured run output belongs in `runs/` rather than at
this level, and a distillation moves the draft it supersedes into `archive/` in the same cycle.
Neither is enforced by `make_index.py --check` — each is a single `git mv` — and between them they
are the difference between a folder that stays readable and one that silts up again.

## Licensed data

The micro stream uses the Findex 2025 **individual-level microdata** (144,090 respondents, 140
economies), licensed for research use with **no redistribution**. `microdata/` is gitignored and
has never been committed. Published outputs contain aggregates and findings only, never raw rows.
To re-run the `U`-series experiments you need your own copy from the World Bank Microdata Library.
