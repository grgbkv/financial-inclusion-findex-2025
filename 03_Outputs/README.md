# 03_Outputs — figures, and the visual system behind them

Every repo-facing chart is generated by one toolchain so the set reads as one system rather than
as thirteen independent charts.

```bash
python3 03_Outputs/build_figures.py         # the 10 analysis figures
python3 03_Outputs/build_ledger_figures.py  # the 3 research-ledger figures
```

Both write **light** into `figures/` and **dark** into `figures/dark/`, same filenames. The
README pairs them with `<picture>` so GitHub serves the right one for the reader's theme.

| file | what it is |
|---|---|
| `style/findex_style.py` | the visual system: palette, typography, mark helpers, both modes |
| `style/validate_palette.py` | the palette checker — six criteria, scriptable |
| `build_figures.py` | the 10 analysis figures, from `01_Data` |
| `build_ledger_figures.py` | the 3 ledger figures, from `05_AutoResearch/findings.tsv` |
| `figures/`, `figures/dark/` | 13 PNGs each |

## The palette is checked, not chosen

`validate_palette.py` runs six checks on any candidate palette — OKLCH lightness band, chroma
floor, colour-vision-deficiency separation (Machado et al. 2009 at severity 1.0), a
normal-vision separation floor, and contrast against the chart surface.

```bash
python3 03_Outputs/style/validate_palette.py "#2a78d6,#eb6834,#1baf7a" --mode dark --pairs all
```

**It rejected two palettes that looked fine.** A four-hue regional scheme failed the
normal-vision floor in dark mode (blue against violet, ΔE 9.8 against a floor of 15) — and every
substitute fourth hue failed in one mode or the other. Rendering the World Bank aggregate as a
third coloured series failed too (orange against red, ΔE 7.1). Both fixes are in the figures now:

- **Three categorical hues, never a fourth.** Blue, orange, aqua clear every check on all pairs in
  both modes. The fourth regional line — High income — is drawn as a neutral dashed *benchmark*,
  which is what it is: the ceiling the other regions are converging toward, not a peer category.
- **The published aggregate is an annotation, not a series.** Hollow diamonds in neutral ink, the
  same on every figure.
- **Aqua carries the relief rule** in light mode (2.74:1 against the surface), so any aqua series
  also carries a visible direct label.

## What is deliberately not restyled

`04_Paper/figures_print/` is untouched. Those figures belong to a **published** paper whose PDF of
record cannot be rebuilt here — `build_paper.py` emits `.docx` only, and the PDF was exported from
Word — so restyling them would leave the repo's own paper inconsistent with its own figures. They
stay as the paper printed them. If the paper is ever rebuilt end to end, that is the moment to
bring them onto this system.
